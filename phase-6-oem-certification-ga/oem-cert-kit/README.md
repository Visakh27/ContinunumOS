# OEM Certification Kit

Documented hardware compliance suite (driver coverage, power
management, Secure Boot chain) OEM partners must pass before a device is
listed as "Continuum OS Certified." Builds on the certification
checklist in
`../../docs/architecture/03-driver-hardware-strategy.md#certification-checklist-feeds-phase-6`.

Includes production key-enrollment process for OEM factories (complement
to `../../phase-0-foundation/boot/secure-boot/enroll-keys.md`'s
reference-hardware dev-enrollment process).

Skeleton only.
