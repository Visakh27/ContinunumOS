# Companion Android Stub

Protocol-level interface stub the Android Companion app
(`../../android-companion/`) is built against, kept here so the desktop
and Android sides can develop against the same contract without the
Android module needing to depend on desktop-side Rust code directly.
Mirrors `../continuumd/src/dbus_api/` and `../pairing/pairing.proto`
(once added). Skeleton only.
