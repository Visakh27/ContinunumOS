# HIL test skeleton: drop throughput KPI

Target: >= 80% of raw Wi-Fi Direct link speed (plan Section 16).
Measure raw link speed with a baseline tool, then transfer 100 MB and 1 GB files; compute the ratio per device pair. Record whether Wi-Fi Aware was available. Include a transfer with a forced mid-transfer disconnect to measure resume overhead.
Blocked on a Tier-1 device (P0-1) and the OEM device matrix.
