# App Runtime (ContinuumKit Sandbox)

Sandboxed, capability-scoped app runtime per ADR 0004
(`../../docs/adr/0004-app-sandbox-format.md`). Gets Flatpak-format Linux
apps running with minimal porting.

## Also owns (added scope)
- ContinuumKit accessibility-tree API (`../../cross-cutting/accessibility/`)
- Capability-broker UI (macOS-TCC-style per-capability prompts, see
  `../../docs/architecture/07-security-permission-model.md`)

Skeleton only.
